# C# Basics Assignment

This repository contains my solutions for the C# Basics Assignment.

## Topics Covered

* Project Structure
* Variables and Data Types
* Implicit and Explicit Casting
* Boxing and Unboxing
* Parsing
* Value Types vs. Reference Types
* Scope
* Compound Assignment Operators
* Bitwise Operators
* Stack and Heap
* Code Organization and Comments

## Project Structure

```text
CSharpBasicsAssignment/

├── CSharpBasicsAssignment.csproj

```

## Parts

### Part A — Project & Structure

Explains the purpose of `.csproj`, `Program.cs`, `obj/`, and `bin/`.

### Part B — Variables, Types & Casting

Demonstrates different data types, implicit and explicit conversions, integer division, boxing and unboxing, parsing, and float-to-decimal conversion.

### Part C — Value vs. Reference Types

Demonstrates the difference between structs and classes using `Point` and `Order`.

### Part D — Scope & Operators

Demonstrates field, method, and block scope, compound assignment operators, and bitwise operators.

### Part E — Stack & Heap

Contains diagrams showing how references and objects are stored in the stack and heap.

### Part G — Short Answers

Contains answers about project properties, `#region`, XML documentation comments, and global variables in C#.

## How to Run

1. Open the solution file in Visual Studio.
2. Build the project.
3. Run the application.
